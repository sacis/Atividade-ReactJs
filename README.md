# Sebos e Molhados

Atividade de React.js da disciplina de Engenharia de Software da UCSAL.

É a página de um sebo de Salvador feita em React com Vite. Ela usa os seis componentes pedidos na atividade: acordeão nas perguntas frequentes, paginação no catálogo, barra de progresso no envio da lista de leitura, abas nas informações da loja, menu suspenso nos filtros do catálogo e notificações toast nas ações da página.

Para o desafio extra foi usada a Context API, com um contexto para as notificações e outro para a sacola de compras.

Para rodar o projeto, instale as dependências com npm install e depois rode npm run dev.
